# 参考写真との比較

左が参考写真、右がこのモデルを同じ角度から描いたもの。`./run.sh compare` で作り直せる(`--blend` で写真と半透明に重ねた絵も out/compare/ に出る)。
カメラの位置と焦点距離は、写っているゴールポスト(高さ 12 m、間隔 5.6 m)の見かけの大きさと位置から計算して置いた。03 は芝のライン 20 点から最小二乗で解き直した(平均 1.2 画素)。01 と 02 は数度のずれが残る。見つかった違いは [../remaining.md](../remaining.md)。

参考写真はすべて Wikimedia Commons のもので、下の作者とライセンスに従って使っている。
CC BY-SA の写真を含む比較画像は、同じ CC BY-SA 4.0 で公開する。写真は大きさだけを変えている。
